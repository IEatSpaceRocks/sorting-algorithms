# Sorting Algorithms
This repository contains my sorting algorithms project. In the following I will explain each separate version, broken down to plans and already achieved capabilities:

**Filename:** `sorting-algorithms.py`

This file will contain all kind of sorting algorithms for a 100 item long list of values.

The sorting speed of each algorithm will likely be limited to 20 swaps per second or less, but individual comparisons will be counted and tallied to show efficiency in this way.
### v0.1 - v0.#
*03/09/2026 - current*

The goal in the v0.# versions is to set up an environment where implementing different kind of sorting algorithms can be done in a quick and straightforward way.

**Capabilities:**
- screen for displaying the values as columns (higher column = bigger value)
- resizable screen, UI adapts to screen size automatically
- a simple way to reshuffle the list
- a simple way to save, and load saved lists
- a way to show which columns the sorting algorithm compares at a given time (highlighting)
- a simple way of choosing the current sorting algorithm to be ran
- a way to track the efficiency of each sorting algorithm

**Plans:**
- truly resizable settings menu
- *audio-visual features*?

When these features are implemented, the project will move to version v1.#
### v1.0 - 1.#
In these versions of the project my goal will be to add as many different sorting algorithms as I can, ranging from well-known to obscure.
